## 🏛️ Overview & Design Philosophy

An editorial, cinematic developer portfolio crafted for **Shaikh Mohd Mujtaba**. Breaking away from generic SaaS templates, this portfolio implements an **acid-editorial aesthetic** combining deep obsidian surfaces, tactile 35mm analog film grain, volumetric crimson lighting, and high-contrast typography.

* **Full-Bleed Responsive Hero:** Dual-asset adaptive rendering (`<picture>`) serving 16:9 widescreen (`hero_theme_wide_v3.jpg`) and 9:16 mobile portrait (`hero_theme_mobile_v3.jpg`) with authentic portraiture.
* **Scroll Dispersion Engine:** Smooth parallax lens warp, directional blur, and scale dispersion transitioning from the hero cover into Chapter 01.
* **Storytelling Chapters:**
  * **Chapter 01 // The Manifesto:** Engineering philosophy, latency priorities, and academic standing at A.G. Patil Institute of Technology (B.Tech CSE '26).
  * **Chapter 02 // Production Systems:** Flagship architectures including the AI Interview Coach Platform (sub-1.5s TTFT streaming), Orbit Sales Intelligence (<80ms P99 indexing), CampusConnect, and Decentralized EHR.
  * **Chapter 03 // Scientific Monograph:** Peer-reviewed cryptographic research monograph published in the *International Research Journal of Modernization in Engineering Technology and Science (IRJMETS)*.
  * **Chapter 04 // Academic Foundations:** Computer Science coursework and foundational scientific training.
  * **Chapter 05 // Competency Matrix:** 6-tier technical matrix spanning core CS, Next.js, TypeScript, Node.js, databases, and applied AI pipelines.
  * **Chapter 06 // Epilogue:** Instant clipboard contact triggers and direct communication channels.

## ⚡ Performance & Engineering Benchmarks

* **Bundle Size:** ~201 kB minified JS bundle (70% reduction by eliminating heavy WebGL CPU loops).
* **Frame Rate:** Deterministic 60fps / 120Hz scrolling using hardware-accelerated CSS `transform: translate3d()` and passive event listeners.
* **Zero CLS & Responsive:** Fully responsive across mobile, tablet, and ultra-wide displays (320px to 4K).

## 🚢 One-Click Deployment (Vercel)

This project is optimized for zero-configuration instant deployment on [Vercel](https://vercel.com):

1. Push this repository to GitHub.
2. In Vercel, click **Add New Project** and import the repository.
3. Keep default settings (Framework preset: `Vite`, Build command: `npm run build`, Output directory: `dist`).
4. Click **Deploy**.
